# Restaurant Images Folder (`/public/kitchens/`)

Tum apni PNG images yahan upload kar sakte ho:

- `public/kitchens/azad.png` (Azad Restaurant)
- `public/kitchens/naaz.png` (Mangalore Naaz Restaurant)
- `public/kitchens/madras.png` (Cafe Madras)
- `public/kitchens/ramashray.png` (Ramashray)

App default mein `.png` load karta hai aur agar `.jpg` ho toh automatic fallback bhi karta hai!
